# Futebol Mod (Fabric 1.21.1)

## Como jogar
- **Bola de Futebol** (aba Ferramentas): clique direito num bloco para colocar a bola em campo.
- **Clique esquerdo** na bola: chute forte (correndo = mais forte; espere a recarga do ataque).
- **Clique direito** na bola: passe curto. **Agachado + clique direito**: pega a bola de volta.
- **Esbarrar/correr** na bola: conduz a bola (drible).
- **Rede do Gol** (aba Blocos): sem colisão. Monte o gol com ela. Quando a bola entra, aparece "GOOOL!"
  com o nome de quem chutou por último, e a bola volta ao ponto onde foi colocada.

## Receitas
- Bola: 4 couros (cruz) + 1 slime no centro.
- Rede do Gol: 4 barbantes (2x2) -> 2 redes.

## Compilar
JDK 21 + IntelliJ (abre a pasta e importa o Gradle). `./gradlew runClient` para testar, `./gradlew build` gera o .jar em build/libs/.
Precisa de Fabric Loader + Fabric API 1.21.1.
